Политика конфиденциальности

Приложение: VetApp
Дата последнего обновления: 13.10.2026
Коротко: VetApp не собирает, не передаёт и не хранит на серверах никакие ваши данные. Вся информация о пациентах и приёмах хранится только на вашем устройстве.

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки информации в мобильном приложении VetApp (далее — «Приложение»). Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

2. Какие данные обрабатывает Приложение

Приложение работает с данными, которые пользователь вводит самостоятельно:

  • Данные владельцев животных: имя, номер телефона.
  • Данные о пациентах (животных): кличка, вид, дата рождения, вес, температура, анамнез, диагноз, лечение, рекомендации.
  • Записи в календаре: дата, время приёма, тип процедуры, заметки.
  • База препаратов и памяток: справочная информация, заполняемая пользователем.

Приложение не обрабатывает медицинские данные человека, финансовую информацию, данные о местоположении, контакты из телефонной книги и иные сведения, не указанные выше.

3. Где хранятся данные

Все данные хранятся локально на устройстве пользователя в защищённом хранилище приложения (localStorage WebView).

Приложение не отправляет данные на серверы, не использует облачные сервисы, не собирает аналитику и не имеет доступа к интернет-сервисам, кроме одного случая, указанного в разделе 4.

4. Единственное сетевое взаимодействие

При запуске Приложение проверяет наличие обновлений, обращаясь к публичному файлу version.json, размещённому на GitHub Pages. При этом:

  • Передаётся только версия приложения (для сравнения).
  • Никакие данные пациентов или пользователя не отправляются.
  • Запрос анонимный, не содержит персональной информации.

5. Экспорт и резервное копирование

Пользователь может самостоятельно создать резервную копию своих данных через раздел «Бэкап» в Настройках. Файл сохраняется в формате JSON на устройстве и передаётся только туда, куда пользователь решит его отправить (Telegram, почта, облако). Приложение в этом процессе не участвует.

6. Разрешения

Приложение запрашивает следующие разрешения:

  • Уведомления (POST_NOTIFICATIONS) — для напоминаний о записях и вакцинациях.
  • Точные напоминания (SCHEDULE_EXACT_ALARM) — чтобы уведомления приходили в назначенное время.
  • Вибрация (VIBRATE) — для звукового и вибросигнала уведомлений.
  • Интернет (INTERNET) — только для проверки обновлений.
  • Файлы (READ/WRITE_EXTERNAL_STORAGE) — для сохранения и восстановления бэкапа.
  • Установка обновлений (REQUEST_INSTALL_PACKAGES) — для автоматического обновления приложения с подтверждением пользователя.

Разрешения используются исключительно для заявленных функций и не передают данные третьим лицам.

7. Передача данных третьим лицам

Приложение не передаёт данные пользователя третьим лицам, за исключением случаев, прямо предусмотренных законодательством Российской Федерации. Данные не используются для рекламы, аналитики или маркетинга.

8. Удаление данных

Пользователь может удалить все свои данные в любой момент через раздел «Опасная зона» в Настройках Приложения. Также все данные удаляются при удалении Приложения с устройства.

9. Безопасность

Приложение не требует регистрации, не создаёт учётных записей, не использует пароли. Данные защищены на уровне операционной системы Android. Доступ к ним имеет только владелец устройства.

10. Изменения в Политике

Разработчик вправе обновлять настоящую Политику. Актуальная версия всегда доступна по адресу: https://warizernir.github.io/vetapp/privacy.html

11. Контакты

По всем вопросам, связанным с обработкой данных, обращайтесь по электронной почте, указанной в карточке Приложения в RuStore.
